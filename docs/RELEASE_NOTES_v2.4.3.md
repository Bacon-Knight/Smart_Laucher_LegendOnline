# 🥓 Bacon Knight Launcher LO - Versão 2.4.3

Bem-vindo à versão **v2.4.3** do **Bacon Knight Launcher Legend Online**! Esta atualização traz importantes correções de usabilidade, novo sistema de aviso de atualizações e suporte para compilação nativa.

---

### ✨ Novidades e Correções da Versão 2.4.3

* 🚀 **Novo Pop-up de Atualização com Patch Notes**:
  Agora, quando houver uma nova versão do Launcher disponível no GitHub, uma janela modal moderna e destacada é exibida com as novidades completas e um botão de download direto.
* 🛑 **Correção Definitiva do Modo Trabalho / Modo Chefe**:
  Corrigido o problema onde as janelas do jogo eram enviadas para a bandeja do sistema (tray) mesmo com o "Modo Trabalho" desmarcado. Agora a janela minimiza normalmente para a barra de tarefas do Windows.
* 🔒 **Preparação para Compilação Nativa (Cython)**:
  Estrutura do projeto preparada para compilação estática de módulos Python em código C nativo (`.pyd`).
* ⚡ **Ajustes de Desempenho e Estabilidade**:
  Otimizações gerais na resposta dos temporizadores e gerenciamento de memória.

---
